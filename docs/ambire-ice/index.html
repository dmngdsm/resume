3 · Name and brand

Ambire's logo is fire. So we called it Ice.

We're the first hot wallet to make its own cold wallet.

Hot wallet
Cold wallet

For security reasons we chose a transparent case.

Most hardware wallets look serious, however we thought that making Ice playful is a security feature on its own, as people might think it’s a small handheld console, instead of a financial tool.

The transparent console direction reminded us of the iconic early-2000s Frutiger Aero era: the clear Game Boy, the iMac G3.

So we decided on an opulent 3D-rendered logo and a minimal version for engraving the case.

    8 · Takeaways

    What we'd do again

    1. Build a good product

      It is easy to market a good product.

    2. Engineering as marketing

      Transparent case, open-source, shipping to PO boxes only. These are all features that market the product on their own.

    3. Make branding fun again

      Dare to defy industry standards and be playful.

    4. Use video

      This is not news, but video performs outstandingly on X. It is a must for launches.

    5. Set an offer, but with limitations

      The first batch got a good discount, but was limited to 200 devices only, so it created a sense of urgency.
